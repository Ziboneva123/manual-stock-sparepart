2. Alur Kerja Operator

A. Cek kondisi

  1. Login ke Web Main.
  2. Periksa Dashboard dan status stok.
  3. Buka Data Sparepart untuk detail.

B. Transaksi

  1. Barang Masuk untuk penambahan.
  2. Barang Keluar untuk pengambilan.
  3. Pastikan Operator, Jumlah, dan Keterangan benar.

C. Pemeliharaan master

  1. Cek Data (Duplikat) secara berkala.
  2. Jika aman, jalankan Perbaiki Data Otomatis.
  3. Jika hasil tidak sesuai, gunakan Undo Perbaikan Otomatis.

D. Laporan

  1. History Transaksi untuk pemeriksaan.
  2. Export History Excel untuk arsip.
  3. Export Excel untuk master.

3. Aturan Status Stok

Status ditentukan dari Stock dan Minimum Stock.

HABISStock ≤ 0
LOWStock > 0 dan Stock ≤ Minimum Stock
OKStock > Minimum Stock
Perhatian: stok sama dengan minimum sudah termasuk LOW.

Prosedur

  1. Buka Tambah Sparepart.
  2. Isi Kode Sparepart dan Nama Sparepart.
  3. Isi Lokasi, Stock, dan Minimum Stock.
  4. Gunakan Generator Kode bila diperlukan.
  5. Klik Simpan.
Validasi: Kode dan nama wajib. Stock dan Minimum Stock tidak boleh negatif. Kode baru yang sudah dipakai ditolak.

5. Import & Update Excel

Import tambah data

  1. Pilih Import Excel.
  2. Pilih file Excel.
  3. Pastikan sheet pertama mengenali Kode, Nama Sparepart/Nama, Lokasi, Stock, Min. Stock.
  4. Periksa preview.
  5. Jalankan Import ke Firebase.

Ganti semua

  1. Buka Update Data (Ganti Semua).
  2. Pilih Excel dan periksa preview.
  3. Pastikan memang ingin mengganti master lama.
  4. Konfirmasi Hapus & Ganti Semua Data.
Perhatian: simpan Excel sumber sebagai arsip sebelum operasi massal.

6. Barang Masuk / Keluar

Barang Masuk

Stok baru = stok lama + jumlah masuk.

  1. Pilih kode.
  2. Periksa stok.
  3. Isi Jumlah.
  4. Isi Operator dan Keterangan.
  5. Simpan lalu verifikasi.

Barang Keluar

Stok baru = stok lama − jumlah keluar.

  1. Pilih kode.
  2. Periksa Stock tersedia.
  3. Masukkan jumlah.
  4. Isi Operator.
  5. Simpan. Jumlah melebihi stok ditolak.
Error: “Stock tidak mencukupi.” berarti jumlah keluar melebihi stok terbaru.

7. Duplikat, Auto Fix & Undo

  1. Buka Cek Data (Duplikat) lalu Cek Ulang.
  2. Periksa kelompok kode dan nama/lokasi.
  3. Jika memang duplikat, jalankan Perbaiki Otomatis.
  4. Sistem membuat backup sebelum penggabungan.
  5. Periksa kembali Data Sparepart.
  6. Jika salah, gunakan Undo Perbaikan Otomatis.
Prinsip: pada pemeriksaan auto-fix, kode paling awal (angka terkecil) dipertahankan sebagai data utama.

8. QR Code

Scan QR Code

  1. Buka Scan QR Code.
  2. Berikan izin kamera.
  3. Arahkan kamera ke QR.
  4. Periksa kode, nama, lokasi, stok, minimum, status.
  5. Lanjutkan Barang Masuk/Keluar bila diperlukan.

QR master

  1. Download Semua QR untuk paket.
  2. Print Semua QR untuk alur cetak.
  3. Detail item → Cetak QR.
  4. Jika popup diblokir, izinkan popup situs.

9. History & Export

  1. Buka History Transaksi.
  2. Atur Dari Tanggal dan Sampai Tanggal.
  3. Gunakan reset/semua tanggal untuk kembali.
  4. Periksa jenis, jumlah, operator, dan keterangan.
  5. Export History Excel untuk arsip.

Kolom export: Tanggal, Kode, Nama Sparepart, Lokasi, Jenis, Jumlah, Operator, Keterangan.

10. FITRIYANI NUR CAHYATI — AI Pembantu Stock

Pertanyaan cepat

  • Apa saja barang yang habis?
  • Apa saja yang perlu direstock?
  • Berapa total stock semua barang?
  • Ada berapa transaksi hari ini?

Cara pakai

  1. Buka FITRIYANI NUR CAHYATI.
  2. Pilih pertanyaan cepat atau tulis pertanyaan.
  3. AI membaca item dan transaksi dari Firebase.
  4. Untuk keputusan penting, verifikasi pada master/history.

11. Web User

Web User menggunakan parameter code pada URL untuk menampilkan satu sparepart. Pengguna dapat melihat kode, nama, lokasi, minimum stock, deskripsi, stok dan status.

  1. Buka URL Web User dengan kode yang benar.
  2. Periksa detail sparepart.
  3. Untuk pesan admin, isi Nama Operator dan Pesan untuk Admin.
  4. Untuk ambil barang, isi Jumlah diambil, Nama Operator, dan Keterangan.
  5. Pengambilan melebihi stok terbaru ditolak.
